Employee Management

O Employee Management é um projeto desenvolvido em Java com o objetivo de praticar e reforçar os fundamentos da Programação Orientada a Objetos (POO) e da lógica de programação.  
Trata-se de uma aplicação totalmente executada via console, voltada para o gerenciamento de projetos e funcionários, incluindo gerentes e desenvolvedores.

O foco deste projeto foi o estudo dos conceitos essenciais de POO, como abstração, encapsulamento, herança e polimorfismo, além do uso de enums, associações entre classes e
camadas de serviço para organizar o código.  
Tudo foi feito de forma simples e direta, sem o uso de frameworks ou recursos complexos, com o intuito de compreender profundamente a base da linguagem e suas boas práticas.

Esse projeto representa uma etapa de aprendizado essencial, onde o principal objetivo não é a complexidade, mas sim o domínio dos fundamentos da orientação a objetos e da
lógica aplicada em Java.
